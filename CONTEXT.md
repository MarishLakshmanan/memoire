# AI Notes

A shared notes store for AI chat sessions. A user summarises a session with one AI tool, saves it here, and references it from a different AI tool later — so context can cross between assistants that cannot see each other's conversations.

## Language

**Notebook**:
The top-level container for one project or topic. Holds an ordered list of Notes and belongs to exactly one user.
_Avoid_: root node, node-0, graph, collection, thread

**Note**:
A summary of a single AI chat session, saved into a Notebook. Notes are siblings ordered by creation time; a Note is never the parent of another Note.
_Avoid_: node, node-n, child node, chat, entry

**Roll-up Summary**:
A narrative summary of an entire Notebook, written by an LLM across all of its Notes. Optional, and only exists once a user explicitly asks for one.
_Avoid_: root summary, node-0 content, master summary

**Derived Summary**:
The fallback view of a Notebook, assembled from its Notes' titles and summaries with no LLM involved. Used whenever a Notebook has no Roll-up Summary, and appended to a stale one to cover Notes it predates.
_Avoid_: auto summary, generated summary

**Source App**:
The AI client that created a Note, established from the authenticated OAuth client rather than supplied by the model. A closed set.
_Avoid_: tag, client, origin, platform

**Tag**:
A free-text topical label on a Note, supplied by the model at save time. A Note may carry several.
_Avoid_: category, source app

**Chat Link**:
An optional URL to the original conversation. Supplied by the user only — never generated by a model, which cannot know its own conversation's URL.
_Avoid_: source url, permalink
